Telco_Customer_Churn.csv

1. DATASET INFORMATION
This dataset contains information about a fictional telecommunications company. Each row represents a customer, and the columns contain customer attributes. The "Churn" column indicates whether the customer left within the last month. The dataset is often used for predicting customer churn. 

Rows: 7,043

Columns: 21

2. SOURCE INFORMATION
Original File Name: Telco_Customer_Churn.csv
Source URL: https://www.kaggle.com/datasets/mosapabdelghany/telcom-customer-churn-dataset
Format: Comma-Separated Values (CSV)
